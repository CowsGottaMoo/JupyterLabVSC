# JupyterLabVSC

Version-controlled repository for homework assignments, lecture materials, notes, and Jupyter notebooks for the course **Scientific Programming with Python**.

## Overview

This repository is used to organize and track course-related work created during the semester. It includes Python scripts, Jupyter notebooks, assignment solutions, lecture data, and supporting files used for scientific computing tasks.

The main goals of this repository are:

- to keep homework assignments and lecture files organized
- to document progress over time using Git version control
- to make notebooks reproducible and easier to review

## Repository Structure

```text
JupyterLabVSC/
├── lectures/            # Lecture notebooks, examples, and course materials
├── homework/            # Additional Jupyter notebooks and experiments
└──  README.md           # Project documentation
```


## Tools Used

This repository is intended to be used with:

- **Python**
